## Goal
Theo likes the current squared-rubble wall with the procedural limestone faces (T-180). He wants more stone types: similar to each other, nothing drastically different, but identifiably different, so walls, piers, arches, vaults and floors can each use a fitting kind. Today scripts/art/procgen/stones.py has LOOKS for ashlar, rubble, squared_rubble, field, wedge and voussoir, and make(kind, rng, size, name, triangles), which stonelib.Library (procgen/stonelib.py) calls to build a library of unique stones per kind. Do not edit stones.py or stonelib.py (T-177). Instead write scripts/art/procgen/stonekinds.py exposing KINDS (a dict of looks) and make(kind, rng, size, name, triangles) with the same contract as stones.make: returns a Blender object, local axes with the front face on local -y, a 'Color' corner attribute (G = tone, B = fresh faces), and a box-projected UV. You may import and reuse stones.core_block/detail/_cut. Kinds to make: (1) dressed ashlar: near-rectangular, crisp but worn arrises, fine tooled face (light batter/claw marks) and chamfered edges; (2) thin coursed slabs: long flat stones 6-12 cm tall, split faces, slightly wavy beds; (3) small squared units: brick-sized 22x10 cm for vault webs and arches; (4) big quoins/plinth blocks: 60-120 cm, heavier chamfers, rock-faced margins with a drafted edge; (5) galleted rubble: irregular stones plus small spall stones to wedge joints; (6) worn floor flags: flat, edge-chipped, dished by wear. They should share the same weathering family as squared_rubble so they sit together. Verify by building one small test wall panel per kind with the existing masonry.Wall from procgen/masonry.py, passing a Library made from your kinds (construct stonelib.Library-like entries yourself if needed, in your own script). Render under a warm point light with the limestone maps from content/environments/procedural_stone_surface_v1/limestone/ in Cycles, and make a contact sheet comparing all kinds. Keep triangles comparable: 120-320 per stone.

## Done when
- stonekinds.py builds all six kinds headless in Blender 5.2; review renders in content/environments/procedural_stone_kinds_v1/review/ show each kind as a wall panel and close-ups; a README describes each kind's intended use (walls, piers, arches, vaults, floors).
