## Goal
The stone-by-stone walls of T-177 need a surface texture for individual stone faces: rough, pitted, grey-brown dressed stone with grit, small chips and darker grime in the pits, like Theo's paintovers (content/art_direction/theo_paintovers_v1). No joints or block pattern in the texture: the geometry supplies the stones. The current marble_rock_03 scan has dark crack veins that read as cracked tiles. Bake procedurally in Blender 5.2 headless (noise, voronoi, musgrave-style layers, erosion-like cavities) to tileable 2048 px maps: albedo.png (sRGB), normal_gl.png (OpenGL), roughness.png, height.png, ao.png. Use the same file names as content/environments/dungeon_pbr_v2/<set>/ so crypt_dungeon.gd surface() can load the folder. Make it seamless (verify by tiling 3x3), physically plausible albedo (stone 0.15-0.35 linear), and give it 2-3 variants (limestone, sandstone, dark granite) in subfolders. Include review renders on a lit sphere and a wall of stones.

## Done when
- Seamless map sets exist under content/environments/procedural_stone_surface_v1/<variant>/ with a README and review renders; tiling shows no seams.
