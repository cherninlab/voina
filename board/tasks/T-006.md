## Goal
Hosts judge client attacks against where the host shows targets now, so clients' hits that looked valid miss and the listen-server host wins trades. Rewind targets on the host by the attacker's measured RTT plus remote-view lag (capped), resolve from the attacker's latest replicated position, back-date client swings by one-way latency (capped). See docs/llm-question-hit-fairness.md.
