## Goal
Age the nave roof trusses, the bell frame and other timber framing with physics, using T-169's `disturb.py` and `fracture.py` (wood material).

1. **Build:** rebuild the framing from the members `DungeonStructure.roof()` and the bell frame create today. Read their geometry; don't edit `gameplay/` files.
2. **Joints:** pegged joints become hinges and pins, and rotten members become weak glue.
3. **Disturb:** run tremor attempts and weight loads, for example the bell hanging.
4. **Classify:** keep a sound version, a sagging version (slipped joints, a cracked rafter), and a partly fallen version, with fallen timbers on the floor.
5. **Output:**
   - a GLB, with AO in Color.R
   - collision only for fallen timbers on walkable floors
   - a report with seed, attempt metrics and sha256
6. **Review:** a contact sheet and an in-engine capture.
7. **Integration:** don't wire it into the game. Hand off to T-162 with the attachment points.

## Done when
- At least 3 conditions each for the nave truss set and the bell frame.
- The calm attempt is untouched.
- No floating members.
- Import and smoke tests pass.
