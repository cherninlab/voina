# Project rules

## Multi-agent coordination (read first)

Several agents edit this repo at once, on two machines and in several sessions per machine, some in the same checkout. Follow [board/README.md](board/README.md):

- Start with `python3 scripts/board.py list -v`, then `claim` a task before touching code; stay inside its `scope`.
- Commit with `python3 scripts/board.py ship --agent NAME -m "..." <exact paths>`. Never `git add -A`/`.`, `commit -a`, `stash`, `reset --hard`, `checkout -- .`, `clean`, rebase or force-push in a shared checkout: other agents' uncommitted work lives there.
- Ship small verified increments often, `sync` before each step, and finish with `done`/`release`/`block`.

## Engine and code

- Target Godot 4.7.2 Standard, typed GDScript, Apple Silicon. Use Mobile/Metal and built-in Jolt; no external physics plugin.
- Read README.md and docs/roadmap.md before expanding the starter. The supplied brief includes future proposals; do not claim those are implemented.
- Explicitly type variables, parameters and return values. Use typed arrays/dictionaries when the schema permits. Variant is allowed at Godot API boundaries such as MultiplayerSpawner.spawn_function.
- Keep ENet creation in core/network_manager.gd. Peer IDs identify players; IPs are connection addresses only.
- Players own movement. Peer 1 owns CombatController (health, stamina, poise, block, phases), attacks, spawning and future match flow. Never put client movement and host health in the same synchronizer. Authenticate any_peer RPCs; clamp/rate-limit client requests.
- Never non-uniformly scale physics bodies or collision shapes. Change resource dimensions. Prefer SkeletonModifier3D over deprecated SkeletonIK3D if rigs are introduced.
- Commit .uid sidecars generated by editor import; never commit .godot/. Use separate local checkouts and Git LFS for binary assets.
- Keep scenes small; no speculative subsystems. No external assets until provenance/license is documented.
- Verify with `"$GODOT" --headless --editor --path . --quit` and `python3 scripts/smoke_test.py "$GODOT"`. Inspect output for errors even when Godot exits zero.
- Run every windowed (non `--headless`) Godot command, such as captures, through `scripts/godot_bg.sh` with the same arguments instead of `"$GODOT"`. The human works on this Mac while agents test: a plain launch steals focus and takes their keystrokes (Esc opens the game menu and spoils your captures). The wrapper keeps the window unfocused behind other windows; rendering and captures are unaffected.
- Headless tests cover combat rules and networking paths only. Report manual camera/input/Tailscale validation separately; do not claim unmeasured latency, bandwidth or thermal results.
