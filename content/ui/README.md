# SECHA title assets

`itsnotthat_splash.png` is the boot splash: the user-supplied it'snotthat logo (supplied 2026-10-21 as a transparent PNG) scaled to 540 px high and centred on a 1920x1080 black canvas. `itsnotthat_icon.png` is the 1024x1024 app icon (`application/config/icon`, also used by the macOS export while its preset icon is empty): the same logo, 620 px wide, on a black rounded square in the macOS icon grid (824 px body, 185 px corner radius).

`secha-menu-grim.png` is a 1920x1080 real Mobile/Metal render of this project's own running village and playable male character. It preserves the actual character mesh, face, black shorts, procedural two-hand sword stance and weapon; no AI character redraw or replacement model. Captured from a front three-quarter camera with the character on the right and native postprocessing/UI hidden; the live menu applies its shared grading once. Existing asset provenance remains in character/environment source folders.

Since T-120 the title no longer shows this still: it is plain black with the branching logo and navigation centred. Existing menu soundtrack remains looped. The previous user-supplied video remains on disk for future use but is not the default background. This PNG is also available directly as the requested menu reference image.
