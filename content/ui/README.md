# SECHA title background

`secha-menu-grim.png` is a 1920x1080 real Mobile/Metal render of this project's own running village and playable male character. It preserves the actual character mesh, face, black shorts, procedural two-hand sword stance and weapon; no AI character redraw or replacement model. Captured from a front three-quarter camera with the character on the right and native postprocessing/UI hidden; the live menu applies its shared grading once. Existing asset provenance remains in character/environment source folders.

The default title now uses this still with a charcoal navigation scrim, the existing branching logo, aged ivory text and amber selection lines. Existing menu soundtrack remains looped. The previous user-supplied video remains on disk for future use but is not the default background. This PNG is also available directly as the requested menu reference image.
