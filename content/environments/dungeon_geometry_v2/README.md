# Dungeon geometry revision

Modular Fort 01 by Rico Cilliers, Poly Haven, CC0 1.0: https://polyhaven.com/a/modular_fort_01
License: https://polyhaven.com/license

Imported glTF kit and its original 2K JPEG material maps. All bytes are checked against Poly Haven API MD5 values; SHA256 values are recorded as well. The complete kit is a source library; individual modules are instantiated in the dungeon. The runtime uses only `thin_gate_01` at the nave front entrance. Its transformed triangle faces are baked into the level collision mesh, with bodies kept at uniform scale. Other kit modules are source material for later selection and are not presented as implemented architecture.

Marble Rock 03 by Amal Kumar is a PBR texture, not a standalone rock model: https://polyhaven.com/a/marble_rock_03
