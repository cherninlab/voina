# Construction study — first connected baseline

This is a construction and attachment pass, not visual acceptance. The wooden bridge deck remains an unsuccessful visual candidate: its repeated profile and close board edges produce conspicuous artifacts. A separate procedural-bridge agent will replace it. Do not mistake passing traversal for acceptable art.

The runtime uses fitted stringers, transoms, wall brackets and grounded tapered piers. Supports derive from route coordinates and nearby wall outlines, not fixed world-axis offsets. The existing irregular route footprint, grades and collision ribbon remain. Nave roof trusses share explicit eave and ridge nodes and bear into room walls. The bell frame has posts reaching its room floor.

## Assets and provenance

- `hewn_timber_*.glb`: original Blender geometry generated by `scripts/art/build_dungeon_structure.py`; metre-unit fitting profiles, exact end planes. Current profile is too strongly repeated on the deck.
- `cloth_drape.glb`: original mesh, simulated in Blender 5.2.2 LTS with gravity and two pinned upper corners for 110 frames, then exported as static geometry. No runtime cloth simulation or new physics dependency. `bake.json` records zero pin drift and maximum edge-length ratio 1.003844. This is cloth shape simulation, not a bridge strength or load-capacity calculation.
- `bearing-reference.png`: built-in ImageGen source. Exact prompt: `bearing-prompt.txt`.
- `raw/bearing_cap.glb`: locally generated CL3D/2mini output from that source, MPS float16, seed 20261024, 50 steps, resolution 384. Raw generation metadata and input hash are adjacent; `.gdignore` excludes raw assets from Godot import.
- `meshes/bearing_cap_lod*.glb`: source cleaned and decimated by `scripts/art/prepare_dungeon_kit.py`; 18,002 / 6,000 / 2,500 triangles. The runtime uses the 6,000-triangle level. `preparation.json` records hashes. The capital's flat seat and shoulders are fitted below transverse bearers.
- Runtime textures reuse the already documented ambientCG CC0 PBR collection in `../dungeon_pbr_v2/`; no additional third-party textures were introduced.

Reproduce the static timber and cloth:

```sh
blender -b --python scripts/art/build_dungeon_structure.py -- content/environments/dungeon_structure_v1
```

`generation.json` records this machine's absolute generation inputs. To regenerate elsewhere, update those paths and run the existing local CL3D `tests/dungeon_kit_01/generate_kit.py`, then run the repository preparation script in Blender. The original pixels and generated meshes are retained.
