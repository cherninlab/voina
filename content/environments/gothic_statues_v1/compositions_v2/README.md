# Statue compositions without pedestals — T-189

Eight initial composition studies, twelve variants of four user-selected designs, and one additional seated study. These are image concepts for selection before CL3D.

The user selected S04 Wall Leaning, S06 Horned Oracle, S01 Bowed Kneeling and S02 Hooded Reaper as successful designs. Their twelve new versions are in the [variant catalogue](variants/README.md). The latest pose-reference follow-up is in [additional studies](additional_poses/README.md).

All figures are inanimate marble, with classical carving and plain drapery. No generated circular/rectangular plinths or primitive architecture are included. Ledges and walls suggested by some poses will need game-built supports. S03 is a mantle-covered antique torso with sculpted breaks; S05, S07 and S08 are independent draped studies using only the approved marble-style reference. S05 resolved as a standing crossed-arm study rather than a bather.

## Provenance and status

Successful native PNGs are byte-preserved. `manifest.json`, `prompts.json`, `prompts/`, `receipts/`, `source-manifest.json` and `generation-notes.json` record the actual inputs and outputs. User-provided imagery is reference material; no external redistribution licence is claimed. Thumbnail sheets are review aids only.

Four parent designs were selected; approval does not automatically extend to their new variants. No CL3D or game placement was performed in this image phase. Reconstruction still needs review of fingers, fine hair, horns, scythes, negative spaces and unseen surfaces.

[Verification](review/verification.json), [Godot import](review/editor-import.txt), [smoke test](review/smoke-test.txt). Godot 4.7.2 import and required smoke test passed with no error lines; this is repository compatibility evidence, not visual or 3D acceptance.
