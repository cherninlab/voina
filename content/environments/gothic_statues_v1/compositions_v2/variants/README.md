# Twelve versions of the four selected sculptures

Three new poses for each approved archetype: wall-leaning figure, horned oracle, kneeling mourner and hooded reaper. All twelve are new image candidates awaiting selection before CL3D. The parent-design selection is recorded in [approval.json](approval.json).

The poses change body weight, knees, arms, head direction and silhouette; oracle horns and reaper scythes also vary. No pedestals are generated. Wall/ledge poses will require supports assembled in the game. W01 retains its original file ID; the final pose is a mantled wall lean with the hand at the shoulder, not an overhead arm.

Native PNGs, final successful prompts, receipts and hashes are retained. Earlier drafts and output screening failures are documented in [generation notes](generation-notes.json). No meshes have been generated from these new images.
