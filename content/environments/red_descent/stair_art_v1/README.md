# Stair halls — restrained ritual art pass

This is an actual game increment on the repaired `366005e` baseline. FIRST now carries one shallow bell-oath medallion with soot-dark recessed eyes/mouth, a pale worn rim and two small votive tablets. SECOND has a sealed vascular reliquary, two witness plaques and short clamped vessels on the visible far wall. The proposed east-wall placement was rejected after the normal camera hid it behind the parapet. Both bays have a narrow eroded seal band on the existing stone faces.

Materials reuse the project's neutral local Krea limestone and fibrous tissue maps, plus the existing oxidized-iron albedo. Walls remain matte; existing tread/coping upper faces have a paler, desaturated wear treatment. Existing floor kerb modules are darkened using their own materials; their original half-metre geometry and clip planes remain. Torch positions, counts and exposure are unchanged. Soot is localized above existing sconces. Shared stone shaders default to the original treatment; only duplicated materials in these two rooms enable the new wear/seal uniforms.

All seven added render meshes are original procedural project art: 22,242 triangles in total. The builder measures the actual bowed/worn stone underneath each fixture and mounts against it, with small fixings; it does not assume a flat wall. Relief depth is compressed to roughly six centimetres. Closed backplates and shallow sealed carvings avoid missing backs or through-holes. The biological insert is a textured sealed membrane, not an emissive opening. Source pieces are checked before joining by hall/material; independent exported checks cover closure, winding and shading normals.

`build.json` pins the source stair hashes and records mounting planes/placements. Runtime installation requires the fitted repair and matching source hashes, and adds no collision or lights. `--no-stair-art` keeps the repaired baseline for comparison. The runtime check installs the art into that baseline and verifies that 4,886 existing visual meshes, 620 collision shapes, floor clip planes and a non-stair room material stay unchanged. The route test remains the real player capsule test, distinct from the exported visual envelope check.

Rebuild with `/Applications/Blender.app/Contents/MacOS/Blender --factory-startup -b --python-exit-code 1 --python scripts/art/build_stair_art.py`. Run `validate.py` in the CherninLab3D Python environment. Source geometry and reused material/reference hashes are documented in `provenance.json`; no new external mesh, download or image-to-mesh reconstruction is used. H-011's local Krea concepts guided motifs only. Their invented stairs, voids and torch counts were discarded.

`review/compare.html` pairs four actual gameplay cameras with the previous repaired game. `review/after/` includes these views plus two close views, each with colour/albedo/object-ID/normal/collision passes, and a wide 3840×2160 first-stair view. Colour is authoritative; diagnostic materials omit shader displacement and peeling. All images are unretouched engine output through the unfocused/silent wrapper.

This first pass is deliberately quieter than the Krea concepts. FIRST's face remains subtle at normal distance; SECOND's insert reads as dark red tissue rather than a complex organic mass. The older thick crimson root cords and conspicuous clipped ends remain a separate baseline defect. Human art acceptance, input/camera feel and two-Mac Tailscale behaviour are not established by automated checks.

Validation receipts under `review/validation/` record clean editor import, independent exported mesh checks, unchanged original geometry/collision/clipping and local material isolation, fresh 1,235 m traversal and the complete isolated core suite PASS. The local ENet test measured 60 host snapshots/s in that run; this is not a two-Mac performance result. Windowed teardown retains the known seven texture-RID and one ObjectDB warnings.
